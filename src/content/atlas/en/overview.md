# Welcome to the Atlas

The Atlas is organized by thematic sections in the left sidebar. You can start with Anatomy or explore Pathology. Use the navigation tree on the left.

- For a section with a subfolder, try: Anatomy → Introduction.
- For a standalone page (no subfolder), you are here: "Atlas Overview".
